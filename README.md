# SupportKK — поиск по базе инструкций

## Переменные Railway
В сервисе бота должны быть заданы:
- `BOT_TOKEN` — токен Telegram-бота
- `DATABASE_URL` — переменная PostgreSQL из Railway

## Возможности
- `/start` — инструкция по использованию
- `/count` — количество сохранённых инструкций
- `/search steam` — поиск по базе
- Обычное сообщение с описанием проблемы тоже запускает поиск
- Сохраняет новые инструкции в PostgreSQL

## Формат добавления инструкции
Отправь боту личным сообщением:

    #Игры
    Проблема: Не запускается Steam
    Решение: 1. Перезапусти Steam.
    2. Проверь подключение к интернету.

Строки `Проблема:` и `Решение:` обязательны. Категория начинается с `#`.
Дубликат с той же категорией и проблемой не добавляется.

## Обновление на Railway
1. Замени файлы `bot.py`, `db.py`, `requirements.txt`, `Dockerfile` файлами из архива.
2. Не удаляй сервис PostgreSQL и не меняй `DATABASE_URL` — существующая база должна сохраниться.
3. Убедись, что запущен только один экземпляр/реплика бота. Несколько процессов polling могут вызвать `TelegramConflictError`.
4. После деплоя проверь `/count`, затем отправь `/search steam`.
