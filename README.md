# SupportKK — улучшенный поиск без OpenAI API

## Что добавлено
- Поиск по синонимам и похожим формулировкам без внешнего API.
- Распознавание вариантов названий FACEIT/Фейсит и Steam/Стим.
- Группы понятий для проблем запуска, вылетов, зависаний, служб, интернета,
  авторизации, обновлений, звука, чёрного/синего экрана, FPS и установки.
- Существующий формат ответов сохранён: заголовок, проблема и решение выделены,
  переносы строк отображаются корректно.

## Команды
- `/start` — инструкция по использованию
- `/count` — количество инструкций в базе
- `/search фейсит не стартует` — поиск
- Обычное сообщение с описанием проблемы тоже запускает поиск

## Формат добавления инструкции
    #FACEIT
    Проблема: Не запускается FACEIT
    Решение: Перезапустить службу

## Обновление на Railway
1. Замени файлы `bot.py`, `db.py`, `requirements.txt` и `Dockerfile` файлами из архива.
2. Не удаляй PostgreSQL и не меняй `DATABASE_URL`. Схема базы не меняется.
3. Убедись, что запущен только один экземпляр бота.
4. После деплоя проверь `/count`, затем протестируй:
   - `фейсит не стартует`
   - `FACEIT не открывается`
   - `стим не запускается`
   - `игра вылетает`

Это локальный поиск по набору правил и синонимов, а не полноценная языковая модель:
качество зависит от словаря, который можно расширять по результатам тестирования.
